You can explore now and connect a coding CLI before your first agent run. In PowerShell, use winget install --id Git.Git --exact --source winget, then the command for your CLI below. Sign in through that CLI and reopen AgentFlow after installation.

  • Claude Code: winget install --id Anthropic.ClaudeCode --exact --source winget

  • Copilot: winget install --id GitHub.Copilot --exact --source winget

Jira is optional. Leave its fields blank to use local prompt tasks; when updating a configuration, blank fields keep its Jira settings if they are complete. After an error, re-enter your token if configuring Jira.

The token is stored in your local config.json, using AgentFlow's existing format. Setup validates the fields locally. Jira authentication is checked when you use Jira.

For Jira Cloud, the Atlassian MCP URL is https://mcp.atlassian.com/v2/mcp. Configure it in your coding CLI. AgentFlow also uses your Jira REST connection for ticket sync.

Embedded terminals are included. Python, Node.js and Zellij are not required to run this desktop installation. Optional Slack, GitHub and advanced role settings use the existing configuration format.
